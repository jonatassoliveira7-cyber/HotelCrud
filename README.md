# 🏨 Hotel Primavera - Sistema de Gerenciamento

Sistema web completo para gestão hoteleira, desenvolvido em **ASP.NET Core MVC**. A aplicação conta com autenticação de usuários, controle de acesso e operações completas de CRUD para hospedagem e serviços.

---

## 📌 Funcionalidades Principais

- **🔑 Autenticação de Usuários:** Tela de login limpa e segura com validação de credenciais e controle de sessão.
- **👥 Gestão de Hóspedes:** Cadastro, edição, listagem e remoção de hóspedes.
- **🛏️ Gestão de Quartos:** Controle de disponibilidade, tipos de acomodação e valores de diárias.
- **🛎️ Serviços:** Cadastro e controle de serviços oferecidos pelo hotel.
- **👔 Equipe/Funcionários:** Gerenciamento dos dados e cargos da equipe interna.
